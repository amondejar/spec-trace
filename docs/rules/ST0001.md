# ST0001: Requisito desconocido

| Severidad por defecto | Se reporta en |
| --- | --- |
| Error | Código |

## Qué significa

Un `[Implements]` o `[Verifies]` usa un ID que no está definido en ninguna spec `*.spec.md`.

## Ejemplo

```text
[Implements("ORD-01")]   // la spec define ORD-001
```

## Cómo arreglarlo

Corrige el ID o añade el requisito a la spec. Si usas las constantes `Requirements.XXX`, este error no puede ocurrir: un ID inexistente ni siquiera compila.

## Code fix en el IDE

**Cambiar a 'ORD-001'**: propone hasta tres IDs existentes parecidos (por distancia de edición).

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0001.severity = error   # o warning, suggestion, none
```
