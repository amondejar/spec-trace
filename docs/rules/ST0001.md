# ST0001: Unknown requirement

| Default severity | Reported on |
| --- | --- |
| Error | Code |

## What it means

An `[Implements]` or `[Verifies]` attribute uses an ID that is not defined in any `*.spec.md` spec.

## Example

```text
[Implements("ORD-01")]   // the spec defines ORD-001
```

## How to fix it

Fix the ID, or add the requirement to the spec. If you use the `Requirements.XXX` constants this cannot happen: an unknown ID does not even compile.

## IDE code fix

**Change to 'ORD-001'**: offers up to three similar existing IDs (by edit distance).

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0001.severity = error   # or warning, suggestion, none
```
