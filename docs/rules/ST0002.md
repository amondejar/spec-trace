# ST0002: Unknown acceptance criterion

| Default severity | Reported on |
| --- | --- |
| Error | Code |

## What it means

`[Verifies]` names an `AC-n` criterion that the requirement does not have.

## Example

```text
[Verifies("ORD-001", "AC-9")]   // ORD-001 only has AC-1 and AC-2
```

## How to fix it

Use one of the requirement's criteria, or add the missing criterion to the spec.

## IDE code fix

**Change to 'AC-1'** / **'AC-2'**…: one option per valid criterion.

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0002.severity = error   # or warning, suggestion, none
```
