# ST0002: Criterio de aceptación desconocido

| Severidad por defecto | Se reporta en |
| --- | --- |
| Error | Código |

## Qué significa

`[Verifies]` indica un criterio `AC-n` que el requisito no tiene.

## Ejemplo

```text
[Verifies("ORD-001", "AC-9")]   // ORD-001 solo tiene AC-1 y AC-2
```

## Cómo arreglarlo

Usa uno de los criterios del requisito, o añade el criterio a la spec si falta.

## Code fix en el IDE

**Cambiar a 'AC-1'** / **'AC-2'**…: una opción por criterio válido.

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0002.severity = error   # o warning, suggestion, none
```
