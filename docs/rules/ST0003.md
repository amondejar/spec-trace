# ST0003: Requisito sin implementar

| Severidad por defecto | Se reporta en |
| --- | --- |
| Warning | Spec |

## Qué significa

Un requisito `approved` o `implemented` no tiene ningún `[Implements]` en el proyecto. Solo se comprueba en proyectos de implementación (no de test).

## Ejemplo

```text
## ORD-003: Aplicar cupón de descuento
Status: approved      ← ningún método tiene [Implements("ORD-003")]
```

## Cómo arreglarlo

Implementa el requisito y marca el tipo o miembro con `[Implements(Requirements.ORD_003)]`. Si aún está en discusión, cámbialo a `Status: proposed`.

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0003.severity = error   # o warning, suggestion, none
```
