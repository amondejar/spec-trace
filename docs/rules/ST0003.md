# ST0003: Requirement not implemented

| Default severity | Reported on |
| --- | --- |
| Warning | Spec |

## What it means

An `approved` or `implemented` requirement has no `[Implements]` in the project. Only checked in implementation projects (not test projects).

## Example

```text
## ORD-003: Apply discount coupon
Status: approved      <- no method has [Implements("ORD-003")]
```

## How to fix it

Implement the requirement and mark the type or member with `[Implements(Requirements.ORD_003)]`. If it is still under discussion, change it to `Status: proposed`.

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0003.severity = error   # or warning, suggestion, none
```
