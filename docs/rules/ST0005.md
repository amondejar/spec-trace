# ST0005: Acceptance criterion without a test

| Default severity | Reported on |
| --- | --- |
| Info | Spec |

## What it means

The requirement has tests, but some `AC-n` criterion has no active `[Verifies(id, "AC-n")]`.

## Example

```text
- AC-2: Given a Shipped order, when it is cancelled, then the request is rejected.   <- no test
```

## How to fix it

Add the test for that criterion. To enforce it in CI, raise the severity to warning or error in `.globalconfig`.

## IDE code fix

The same **Generate tests** refactoring only creates the missing criteria.

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0005.severity = error   # or warning, suggestion, none
```
