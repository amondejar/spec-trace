# ST0005: Criterio de aceptación sin test

| Severidad por defecto | Se reporta en |
| --- | --- |
| Info | Spec |

## Qué significa

El requisito tiene tests, pero algún criterio `AC-n` no tiene un `[Verifies(id, "AC-n")]` activo.

## Ejemplo

```text
- AC-2: Given a Shipped order, when it is cancelled, then the request is rejected.   ← sin test
```

## Cómo arreglarlo

Añade el test del criterio. Para exigirlo en CI, sube la severidad a warning o error en `.globalconfig`.

## Code fix en el IDE

La misma refactorización **Generar tests** solo crea los criterios que faltan.

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0005.severity = error   # o warning, suggestion, none
```
