# ST0006: Deprecated requirement

| Default severity | Reported on |
| --- | --- |
| Warning | Code |

## What it means

A requirement marked `Status: deprecated` is referenced. The constants of deprecated requirements also carry `[Obsolete]`, so you will see CS0618 too.

## Example

```text
[Implements("ORD-004")]   // ORD-004 is deprecated
```

## How to fix it

Remove the code or the reference, or reactivate the requirement in the spec if it still applies.

## IDE code fix

**Remove the reference to the deprecated requirement**: removes the attribute and keeps XML doc comments.

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0006.severity = error   # or warning, suggestion, none
```
