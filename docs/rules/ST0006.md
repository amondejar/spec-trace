# ST0006: Requisito obsoleto

| Severidad por defecto | Se reporta en |
| --- | --- |
| Warning | Código |

## Qué significa

Se referencia un requisito marcado `Status: deprecated`. Las constantes de los requisitos obsoletos llevan además `[Obsolete]`, así que también verás CS0618.

## Ejemplo

```text
[Implements("ORD-004")]   // ORD-004 está deprecated
```

## Cómo arreglarlo

Retira el código o la referencia, o reactiva el requisito en la spec si sigue vigente.

## Code fix en el IDE

**Quitar la referencia al requisito obsoleto**: elimina el atributo conservando los comentarios XML.

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0006.severity = error   # o warning, suggestion, none
```
