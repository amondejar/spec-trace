# ST0007: ID duplicado en las specs

| Severidad por defecto | Se reporta en |
| --- | --- |
| Error | Spec |

## Qué significa

Un ID de requisito aparece dos veces (en el mismo fichero o en ficheros distintos), o un criterio `AC-n` se repite dentro de un requisito.

## Ejemplo

```text
## ORD-001: Crear pedido
...
## ORD-001: Crear pedido urgente   ← duplicado
```

## Cómo arreglarlo

Renumera uno de los dos. Los IDs no se reutilizan aunque el requisito se retire: usa `Status: deprecated`.

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0007.severity = error   # o warning, suggestion, none
```
