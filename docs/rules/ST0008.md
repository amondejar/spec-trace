# ST0008: Problema de formato en la spec

| Severidad por defecto | Se reporta en |
| --- | --- |
| Warning | Spec |

## Qué significa

Un requisito aprobado no tiene criterios de aceptación o enunciado, o tiene un estado desconocido. Estados válidos: draft, proposed, approved, implemented, deprecated.

## Ejemplo

```text
## ORD-010: Exportar a CSV
Status: wip      ← estado desconocido; además no hay '- AC-1: ...'
```

## Cómo arreglarlo

Completa el requisito. Se recomienda el formato EARS para el enunciado (When/While/If … the system shall …).

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0008.severity = error   # o warning, suggestion, none
```
