# ST0008: Spec format issue

| Default severity | Reported on |
| --- | --- |
| Warning | Spec |

## What it means

An approved requirement has no acceptance criteria or no statement, or has an unknown status. Valid statuses: draft, proposed, approved, implemented, deprecated.

## Example

```text
## ORD-010: Export to CSV
Status: wip      <- unknown status; and there is no '- AC-1: ...'
```

## How to fix it

Complete the requirement. The EARS format is recommended for the statement (When/While/If … the system shall …).

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0008.severity = error   # or warning, suggestion, none
```
