# ST0009: ID de requisito no constante

| Severidad por defecto | Se reporta en |
| --- | --- |
| Warning | Código |

## Qué significa

El argumento de `[Implements]` o `[Verifies]` no es una cadena constante (por ejemplo `null`), así que el analizador no puede saber a qué requisito se refiere.

## Ejemplo

```text
[Implements(null)]
```

## Cómo arreglarlo

Usa `Requirements.XXX` o el ID como literal.

## Code fix en el IDE

Sobre un literal válido, la refactorización **Usar constantes del catálogo de SpecTrace** lo cambia por `Requirements.XXX` (y el criterio por `AcceptanceCriteria.XXX.AC_n`), añadiendo el `using`.

## Configurar la severidad

En un `.globalconfig` en la raíz del repositorio (no `.editorconfig`: varias reglas se reportan sobre ficheros `.md`):

```ini
is_global = true
dotnet_diagnostic.ST0009.severity = error   # o warning, suggestion, none
```
