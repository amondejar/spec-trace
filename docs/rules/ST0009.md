# ST0009: Requirement ID is not a constant

| Default severity | Reported on |
| --- | --- |
| Warning | Code |

## What it means

The argument of `[Implements]` or `[Verifies]` is not a constant string (for example `null`), so the analyzer cannot tell which requirement it refers to.

## Example

```text
[Implements(null)]
```

## How to fix it

Use `Requirements.XXX` or the ID as a string literal.

## IDE code fix

On a valid string literal, the **Use SpecTrace catalog constants** refactoring replaces it with `Requirements.XXX` (and the criterion with `AcceptanceCriteria.XXX.AC_n`), adding the `using`.

## Configure the severity

In a `.globalconfig` at the repository root (not `.editorconfig`: several rules are reported on `.md` files):

```ini
is_global = true
dotnet_diagnostic.ST0009.severity = error   # or warning, suggestion, none
```
